Community · DM · AI Agent — 하나의 미니멀한 메신저로.

Discord의 공동체 구조와 Telegram의 깔끔한 대화 경험, 그리고 zkTalk이 새로 제안하는 멀티 디바이스 AI Agent를 한 레이아웃에서 자연스럽게 엮는 재설계안입니다. 아래 다이어그램은 실제 pixel mockup으로, 개발자가 그대로 CSS로 옮겨도 되도록 수치와 토큰이 일관됩니다.

2 · Information Architecture

좌측 Rail의 5 탭 체계

좌측 Rail은 Chats · Communities · Agents · Inbox · Discover 5 탭으로 재편합니다. 기존 `ui-nav-redesign-plan.md`가 제안한 Kakao 스타일 탭을 이어받되, Agents 탭을 신설하여 1급 시민으로 올립니다. 커뮤니티 서버 아이콘은 그 아래에 붙어 Discord 친숙함을 유지합니다.

zktalk.app — information architecture
구조적으로 달라진 점은 Agents 탭의 신설과, 모든 컨텍스트(Chats/Communities/Agents)에서 동일한 3-col 레이아웃을 유지한다는 것입니다. 사용자는 "파란 액센트 = 사람/커뮤니티, 바이올렛 = Agent/AI"라는 색 규칙 하나만 기억하면 됩니다.

6 · Agent 전용 채널

커뮤니티 안의 "에이전트가 주인인 방"
