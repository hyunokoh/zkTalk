## zkTalk Branding Drafts

Draft logo and icon assets for `zkTalk` and the Korean lockup `모임톡 by zkTalk`.

Included files:

- `zktalk-icon.svg`: app icon draft with navy background
- `zktalk-mark.svg`: symbol-only mark on transparent background
- `zktalk-logo.svg`: English wordmark lockup
- `moimtalk-by-zktalk.svg`: Korean localized lockup

Notes:

- These drafts use editable SVG text for fast iteration.
- Before a final production handoff, convert text to outlines in a design tool if you need font-perfect exports.
